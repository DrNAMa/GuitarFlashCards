# Guitar Flash Cards for Android

Native .NET Android port of the WinForms application.

- Minimum Android version: Android 6.0 / API 23
- Architectures: ARMv7, ARM64, and x64
- Primary device target: Samsung Galaxy A6 (SM-A600AZ)
- UI: adaptive portrait/landscape layout with scrolling for small screens
- Features: Easy, Medium, and Advanced modes; treble and bass clefs; one-tap A–G answers; timed play; score tracking; saved settings; and A–G cheat sheets

Build a debug APK from the repository root:

```powershell
dotnet build GuitarFlashCards.Android\GuitarFlashCards.Android.csproj -c Debug
```
